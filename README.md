# PEPT REX – Customer Feedback Analysis

## 📊 Project Overview

This project analyzes customer feedback collected from beneficiaries
of the Programme Électricité Pour Tous (PEPT).

The objective of the REX (Return on Experience / Lessons Learned)
analysis is to identify customer satisfaction levels, socio-economic
impacts, challenges, and opportunities for improving the program.

## 🎯 Objectives

- Analyze customer satisfaction
- Evaluate the socio-economic impact of PEPT
- Identify payment and service-related challenges
- Analyze customer feedback
- Identify future electricity needs
- Develop recommendations for program improvement

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- SQL
- Power BI
- DAX

## 🔄 Methodology

Excel Survey Data
↓
Data Cleaning
↓
MySQL Database
↓
SQL Analysis
↓
Power BI
↓
REX Findings
↓
Recommendations


## 🔐 Data Privacy

The original customer survey data is not publicly shared because
it contains confidential/customer-related information.

Only anonymized or aggregated results are presented in this repository.
